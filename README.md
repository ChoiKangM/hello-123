# 최강민 자기소개 페이지 기획안

## 콘셉트

**코드를 쓰고, 길을 달리는 최강민**

해달프로그래밍의 최강민을 소개하는 원페이지 사이트. 코딩에 대한 애정과
러닝을 즐기는 일상을 담아, 이력보다 사람의 이야기가 먼저 보이도록 한다.

## 목표

방문자가 짧은 시간 안에 최강민이 누구인지, 무엇을 좋아하는지, 어디에서
작업을 볼 수 있는지 알 수 있도록 한다.

## 페이지 구성

### 1. 첫 화면

- 이름, 해달프로그래밍, 한 줄 소개와 프로필 사진을 배치한다.
- 「만든 것 보기」와 「나에 대해 알아보기」 버튼을 누르면 해당 영역으로 이동한다.

> 안녕하세요, 최강민입니다.  
> 코딩을 좋아하고, 자주 달립니다.  
> 해달프로그래밍에서의 이야기와 제가 만들고 달리는 일상을 소개합니다.

### 2. About me

- 짧은 자기소개와 `코딩`, `러닝`, `해달프로그래밍` 키워드를 보여준다.
- 1994년생 정보는 공개 여부를 정한 뒤 프로필 항목에 넣는다.
- 해달프로그래밍에서 하는 일은 확인된 내용을 바탕으로 작성한다.

> 해달프로그래밍의 최강민입니다.  
> 코딩을 좋아하고 러닝을 많이 합니다.  
> 이곳에는 제가 만든 것들과, 달리며 보내는 일상을 담습니다.

### 3. Coding

- 대표 프로젝트 2~3개를 카드 형태로 소개한다.
- 각 카드에는 프로젝트 설명, 맡은 부분, 배운 점과 공개 가능한 링크를 담는다.
- 기술 스택과 프로젝트 내용은 확인된 정보만 사용한다.

### 4. Running

- 러닝을 좋아하는 이유와 짧은 에피소드를 사진과 함께 소개한다.
- 기록은 공개하고 싶은 경우에만 넣고, 정확한 생활 동선은 공개하지 않는다.

### 5. Contact

- 공개할 GitHub, SNS, 연락 수단을 간결하게 배치한다.

## 디자인 방향

- **분위기:** 따뜻하고 담백한 개발자 페이지
- **색상:** 크림색 배경, 짙은 네이비 글자, 주황색 포인트
- **서체:** 읽기 편한 한글 산세리프와 기술 태그용 모노스페이스
- **이미지:** 자연스러운 프로필 사진과 직접 찍은 러닝 사진
- **그래픽:** 코드 커서와 러닝 경로를 연상시키는 가는 선
- **움직임:** 가벼운 등장 효과와 버튼 반응만 사용하고, 애니메이션 감소 설정을 존중한다.
- **반응형:** 모바일에서도 소개문과 사진을 편하게 볼 수 있도록 구성한다.

## 준비할 콘텐츠

- 프로필 사진 1장과 러닝 사진 2~3장
- 공개 가능한 프로젝트 소개와 링크
- 해달프로그래밍에서 하는 일에 대한 짧은 설명
- 공개할 연락 수단과 1994년생 정보의 공개 여부

## 첫 버전 범위

소개, 코딩, 러닝, 연락처로 이어지는 반응형 정적 페이지를 만든다.
블로그, 실시간 러닝 기록 연동, 관리자 기능은 첫 버전에서 제외한다.

## v1.1 커피챗

- 사이트의 Coffee Chat 영역에서 GitHub 이슈 신청서를 열고, 댓글로 일정을 조율한다.
- GitHub 계정이 필요하며 신청 내용과 댓글은 공개된다. 개인 연락처나 비공개 링크는 적지 않는다.
- 신청 이슈에는 `coffee-chat` 라벨이 붙고 최강민에게 할당된다. 알림은 각자의 GitHub 알림 설정에 따른다.
- 이메일 발송이나 별도의 서버는 사용하지 않는다.
- GitHub Pages는 `v1.1` 브랜치를 배포한다. 이슈 신청서가 작동하려면
  `.github/ISSUE_TEMPLATE/coffee-chat.yml`이 기본 브랜치에도 있어야 한다.
